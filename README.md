An open-world crime game in a fictional Indonesian harbour city: walk, steal a tow truck, outrun the port patrol and reach the last ferry before it leaves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Everything the game needs lives under `game/`; it makes no network request and runs offline.
